Get started with Flightdesk

A local prototype for call transcription and sales coaching.

1. Connect the AI

In the Mac desktop app, click Settings, choose an AI provider (Auto, OpenAI only, or Gemini only), paste your key(s), and click Save. For the developer browser version, copy .env.example to .env, add your keys, and restart the server. Then click Test connection to verify the key before a call. OpenAI keys look like sk-…, Gemini keys like AIza…; both need an API account with billing. A ChatGPT subscription is not an API key.

Never paste keys into chat, issues, or GitHub. Rotate any key that has been shared. Keys are encrypted in macOS secure storage (desktop) or kept in your gitignored .env (browser).

Test by typing a customer question into the conversation box. API usage is billed by the provider.

2. If you see "provider returned 429"

A 429 means the provider rate-limited you or the key is out of quota. Test connection shows the exact cause:

CodeFix
quota_exhaustedAdd billing/credits in the provider console, or switch provider. Retrying cannot fix this.
rate_limitedFlightdesk retries with backoff. Use one audio source, or raise your plan limit.
invalid_keyPaste a real API key; a ChatGPT plan is not an API key.
no_access / model_unavailableChange the model under Advanced in Settings, or switch provider.

In Auto mode a failed request is retried with the other provider, so call audio and transcripts may be sent to both. Only enable providers your consent covers.

3. Set up Mac audio

Start a session manually and allow microphone access. To hear the other side, choose shared tab/screen audio if supported by your browser, or configure a virtual audio device such as BlackHole and route call playback into it. To capture both your microphone and the customer via a virtual device, create and select an aggregate input in Audio MIDI Setup. Test routing and avoid feedback. Microphone alone usually captures only you. Browser audio-sharing support varies by macOS and Chrome version. Using both sources at once doubles transcription requests and can trigger rate limits.

4. Add flight search (optional)

The Amadeus integration is already built in. Get free Amadeus Self-Service test credentials and add them in desktop Settings (or in .env for the browser version). Test-mode fares may be synthetic. Production requires approved access. Results are indicative; this app does not issue tickets. Other providers such as Sabre need a commercial agreement and their own credentials.

Privacy first. Obtain all required consent before starting. Audio and transcripts are sent to OpenAI and/or Gemini, and searches to Amadeus. Never enter payment-card details. Review suggestions and verify all prices and rules before sharing them.

For complete setup, routing details and limitations, see README.md in the project folder.
