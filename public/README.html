Get started with Flightdesk

A local browser-based prototype for call transcription and sales coaching.

1. Connect the AI

In the Mac desktop app, click Settings, paste your OpenAI API key, and click Save. For the developer browser version, copy .env.example to .env, add your key, and restart the server. Test by typing a customer question into the conversation box. API usage is billed by the provider.

2. Set up Mac audio

Start a session manually and allow microphone access. To hear the other side, choose shared tab/screen audio if supported by your browser, or configure a virtual audio device such as BlackHole and route call playback into it. To capture both your microphone and the customer via a virtual device, create and select an aggregate input in Audio MIDI Setup. Test routing and avoid feedback. Microphone alone usually captures only you. Browser audio-sharing support varies by macOS and Chrome version.

3. Add flight search (optional)

Add Amadeus Self-Service credentials in desktop Settings (or in .env for the developer browser version). Test-mode fares may be synthetic. Production requires approved access. Results are indicative; this app does not issue tickets.

Privacy first. Obtain all required consent before starting. Audio and transcripts are sent to OpenAI and searches to Amadeus. Never enter payment-card details. Review suggestions and verify all prices and rules before sharing them.

For complete setup, routing details and limitations, see README.md in the project folder.
